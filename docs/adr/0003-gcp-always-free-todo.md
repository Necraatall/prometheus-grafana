# ADR-0003: Google Cloud Always Free — deferred optional experiment

Status: **PLANNED / NOT IMPLEMENTED**.

Decision: Keep Google Cloud Always Free as a future portfolio TODO in this repository. Do **not** consume the $300/90-day Free Trial credit. Do **not** assume GKE cluster nodes or full ELK fit Always Free limits. Scope is a small, explicitly approved demonstration of free-tier-eligible services only after cost/eligibility research. No automatic cloud deployment and no requirement for local K8s acceptance. If zero-charge cannot be sufficiently assured, record NO_GO and retain local demonstration as full evidence.
